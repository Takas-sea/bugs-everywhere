# Mトリープ

あなたの旅の軌跡から、AIが“撮っていない瞬間”まで描いた絵日記を作るアプリ

## デモ
- デモURL：https://memorytrip.vercel.app/
- 動画：

## 課題
- 観光客が、写真を撮れなかった瞬間も含めて旅行の思い出を残したいという課題を解決する。

## 解決方法
- 旅行中にユーザーが撮影した写真からその日の行動をAIが分析します。
AIは訪れた場所や移動から旅行中の出来事をストーリー化し、写真が残っていない場面もAIによる画像生成で補完します。さらに、ユーザーのプロフィールを反映することで、本人が主人公となった一日の「AI絵日記」を自動生成します。
