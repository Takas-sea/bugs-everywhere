# Mトリープ

あなたの旅の軌跡から、AIが「撮っていない瞬間」まで描く絵日記アプリ

## 課題

旅行中は、すべての瞬間を写真に残せるわけではありません。

移動中の風景や、写真を撮る余裕がなかった出来事など、思い出に残したい瞬間であっても、写真として記録されていないことがあります。

「写真を撮れなかった瞬間も含めて、旅行の思い出を残したい」

Mトリープは、この課題を解決します。

## 解決方法

旅行中に撮影した写真をアップロードすると、AIが写真の撮影時間や場所などの情報をもとに、その日の行動を分析します。

写真同士の時間間隔や訪れた場所、移動の流れから旅行中の出来事を推測し、写真が残っていない場面については、AIによる画像生成でその瞬間を補完します。

さらに、ユーザーのプロフィール情報を反映することで、自分自身が主人公となった一日の「AI絵日記」を自動的に生成します。

旅行が終わったあとに写真を見返すだけで、その日の出来事をひとつのストーリーとして振り返ることができます。

## 主な機能

* 旅行中に撮影した写真をアップロード
* 写真を撮影時間順に自動整理
* 写真の場所や移動の流れをAIが分析
* 写真と写真の間にあった出来事をAIが推測
* 写真が残っていない場面をAI画像生成で補完
* 各シーンに合わせた文章をAIが自動生成
* ユーザーのプロフィールを反映し、自分が主人公の絵日記を生成

## 動かし方

1. その日に撮影した写真をサイトにアップロード
2. 「AIで写真日記を作る」を押す
3. AIが写真を撮影時間順に整理
4. 写真同士の時間間隔が空いている場合、AIがその間に起きた出来事を推測
5. 推測したシーンをAIが画像として生成し、写真の間に挿入
6. それぞれの写真に、AIが考えた文章を付けて「AI絵日記」を生成
7. 完成した絵日記から、その日の旅行を振り返る

## Mトリープの特徴

「撮った写真」だけではなく、「撮れなかった思い出」まで残せる。

Mトリープは、旅行中に残された断片的な写真から、その日の物語をAIによって再構成します。

写真に残っていない時間も含めて一日の思い出を一つの絵日記にすることで、旅行の記録を「写真」から「物語」へ変えるアプリです。
